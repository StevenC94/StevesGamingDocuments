Privacy Policy

Last Updated: April 30, 2025

This Privacy Policy explains how the script used to upload videos to TikTok operates. The script does not collect, store, or transmit any personal data.

  1. Information Collected by the Script
    The script does not collect, store, or transmit any personal data. It processes only the video file that is specified (e.g., C:\path\to\video.mp4) and uploads it to TikTok.
  2. How the Script Uses Information
    The script only processes the video file path provided to upload the video to TikTok. No additional information is tracked or stored by the script.
  3. Data Sharing
    No data is shared with third parties, except for TikTok’s API, which is used solely for uploading the video. TikTok handles any data shared during the upload process according to their Privacy Policy and Terms of Service.
  4. Security
    As no personal data is collected or stored by the script, there are no additional security concerns. However, it is recommended to use a secure internet connection when interacting with TikTok's API to ensure data is protected during the upload process.
  5. Changes to This Privacy Policy
    This Privacy Policy may be updated to reflect any changes in how the script operates or in the third-party services it interacts with. Updates will be posted on this page with the updated date.
